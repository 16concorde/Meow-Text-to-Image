# 喵喵文生图

喵喵文生图是一个面向 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 的轻量插图扩展，也兼容 [TauriTavern](https://github.com/Darkatse/TauriTavern)。它目前仅支持 NovelAI，操作路径简洁，并保留大部分酒馆用户熟悉的聊天内生图方式：从消息中识别图片标签，按需生成插图，再把结果放回原来的位置。

## 提示词

「提示词 → 来源」可选择内置提示词或外部世界书。内置模式默认注入 D0，可修改注入深度。张数、彩蛋位置、主开关、模式与捕捉标签修改后自动保存，确认后更新注入。正文编辑器自动保存，可恢复默认或恢复打开时内容，点击「完成」退出；固定配图任务仅可预览。条目按固定顺序分组，展开和折叠不改变发送内容，不支持新增、删除或排序。

基础配置的「使用同人角色」「开启彩蛋」分别控制相关 Tag 补充与自检；彩蛋任务仍受画面组成开关影响，彩蛋解析可独立关闭。「完整角色样貌 Tag」与「管理角色样貌 Tag」互斥；性向最多选择一项，也可不指定。NSFW 规范开启后，仅在最近两条有效聊天消息命中关键词时发送本体、所选性向及相应自检。重生成与 swipe 排除将被替换的旧回复，续写保留当前回复；不扫描提示词或世界书。关键词默认折叠、只读，进入「编辑」后可添加、删除、恢复默认；清空列表后不会自动触发，仍按字面包含、不区分大小写匹配。

外部模式仅显示来源和捕捉标签，并清空插件内置注入；世界书继续由酒馆管理。捕捉起止标签作为一对保存，并用于内置运行正文；自定义正文中的未知格式需自行适配，宏按原文保留。生成中的协议保持固定，历史原文不被改写。旧版自定义无法安全映射时会暂停内置注入，保留原配置并提示冲突，不会自动覆盖旧稿。提示词保存需要浏览器支持 Web Locks；同源页面修改不同字段可合并，同字段冲突会保留当前草稿并阻止覆盖，可选择读取最新配置。其他宿主页面或扩展对整份设置的并发写入仍受宿主保存协议限制。

「角色管理」可分别管理角色卡、用户设定与聊天开关。聊天管理优先打开当前角色聊天，也可返回选择其他记录。非当前聊天可定向保存本插件的开关，不会切换酒馆窗口或覆盖聊天消息；恢复全局会屏蔽旧聊天覆盖。ST 的开关覆盖独立保存在宿主用户文件中，TT 有定向元数据接口时沿用该接口。聊天身份不明或外部改名无法核实时会停止保存并保留草稿。同源窗口通过 Web Locks 协调写入；缺少该能力时不会保存聊天开关。宿主文件接口不提供跨设备原子条件写入。

## 使用前准备

- 一个可用的 NovelAI 账户和 API Key。
- 一份可以运行的 SillyTavern。

本扩展负责连接 SillyTavern 与 NovelAI，不提供 NovelAI 账户或生图额度。

## 安装

在酒馆的扩展管理中安装本仓库：

```text
https://github.com/AYUUKI-K/Meow-Text-to-Image
```

安装或更新后刷新酒馆页面，已打开的页面需要完整刷新才能载入新脚本。

安装后，从输入框旁的扩展菜单打开「喵喵文生图」。首次启用时，扩展使用内置提示词并安装配套正则；已有外部世界书模式会保留。可在「提示词」页切换来源，内置模式也可导入正则。

## 快速开始

1. 打开「生成」页，填写 NovelAI Key 并等待自动保存完成。使用 Vibe 时，可选择是否在当前设备记住直连 Key；不记住时，刷新页面后需要重新填写。
2. 打开「配置」页，选择模型并调整提示词和生图参数。默认配置已经可以直接使用。
3. 在「提示词」页选择内置提示词，或选择外部世界书并配置自己的提示词模板，让模型按 `image###提示词###` 输出插图标签。例如：

   ```text
   image###1girl, sitting by a window, morning sunlight###
   ```

4. 手动模式下，点击消息中的「生成插图」按钮即可生图。生成完成后，图片显示在该标签原来的位置。

每个标签中的内容作为本次场景提示词。多个标签会分别生成图片；插件不会替你改写场景内容。若你使用其他标签格式，可在「提示词」页设置起始标签和结束标签，捕捉到的第一段内容会作为提示词。

## 生图设置

「生成」页包含自动化和连接设置：

- **手动**：消息中显示生成按钮，由你选择何时生图。
- **回复后生成**：新回复结束后自动生成其中的图片标签。
- **流式生成**：回复仍在输出时，只要完整图片标签已经闭合，就可以开始生成。

自动模式只处理启用期间产生的最新 AI 回复，不会因为打开聊天或切换模式就自动补跑历史标签。历史消息仍可通过生成按钮手动处理。多个任务在本页依序执行；可选启用共享 Key 排队，以协调使用相同 Key 的请求。队列只用于安排请求，具体设置见[队列说明](docs/QUEUE.md)。

无论是否启用云端排队，每次实际发送生图请求前都会随机等待 2～4 秒，包括自动重试；多张图片仍按本地串行队列依次生成。HTTP 429 临时限流后的自动重试仍至少等待 10 秒，默认生图超时仍为 60 秒。

「配置」页中的每套配置保存独立的模型、提示词、画布尺寸、步数、Guidance、种子、采样器、噪声表和可用的 Vibe。可以新增、复制、删除、切换配置，也可以导入或导出 NAI 配置文件。Guidance Rescale 范围为 0～1，非零值使用当前连接的直连通道，需要当前设备可用的 Key；本插件的 V5 配置中该参数禁用且请求值为0，切回支持模型后保留原值。正面由配置风格与本次场景组合，不再使用后置正面。配置例图用于快速查看不同配置的大致效果；生成例图同样会调用 NovelAI。

「尺寸模式」默认使用固定尺寸。选择「AI 选择横竖」后，每张正文图和彩蛋分别采用横图 1216×832 或竖图 832×1216；标记缺失或无效时，使用该配置的「缺失时使用」方向，默认竖图。原固定宽高会保留，AI 生成不会改写它们。普通重绘及 Tag 编辑后的重绘沿用已保存画幅；例图仍为 512×512，测试生图继续使用配置的固定宽高，收藏缺少标记时使用所选配置的回退方向。

内置模式会在运行时附加构图协议，不改写已保存正文；外部世界书由用户自行采用相同规则。方向只识别图片块第一条非空行的 `@orientation: landscape` 或 `@orientation: portrait`，下一行写 Tag。该行不发送给生图接口；普通 Tag 中的 portrait、landscape 不会被当成尺寸指令。协议支持当前捕捉起止符，不会额外调用文字 API 补齐尺寸。

「配置选择 → 选择方式」默认使用单个配置；点击例图即可切换当前生图与编辑配置。选择「多个配置（每张图随机）」并通过例图选中至少两个配置后，每张普通插图会独立、等概率使用其中一套完整配置。选中配置名称前显示 `♡`；多配置模式下，点击例图切换随机池选择，点击铅笔只切换编辑对象，可以编辑未入池的配置。候选不足两个时会提示，普通图片暂不能生成；新增、复制或导入的配置不会自动入池。下方「编辑配置」的例图刷新、放大和参数修改仅操作当前编辑对象。开启「为最后一张图（彩蛋）单独指定配置」后，每条助手回复的最后一个完整正文图片标签使用指定配置；内置模式还需启用有效的彩蛋任务。只有一张图时也适用。彩蛋分隔标记读取插件基础配置的「彩蛋位置」（外部模式沿用已保存值），只识别图片标签和思维链之外的独立一行；缺失或有歧义时按正文尾图处理。流式模式开启尾图覆盖时只保留最后一个候选到回复结束，其余图片依次生成。排队和自动重试沿用首次入队时选定的配置与参数；手动重新生图会重新选择。

Vibe 可在「Vibe」页导入已有编码的官方文件、JSON、ZIP 或内嵌编码 PNG；原图请进入「Vibe 编码」工作区处理，再在配置中选择使用。Vibe 仅适用于 V4 和 V4.5 模型；支持随机选一个候选，或同时使用最多四个。导入、编码、设备保存及模型支持范围详见 [Vibe 使用说明](docs/VIBE.md)。

## 自定义 NovelAI 兼容接口

在「生成」页切换连接方式，填写第三方站点的基础 API 地址或完整生图端点和 API Key。默认自动补全 `/ai/generate-image`，也可选择原样使用完整地址。Vibe 编码地址可从生图地址推导、手动覆盖或禁用；自动推导只表示路径预测，不代表第三方站点支持编码。官方与自定义凭证分别保存。

详细配置、浏览器网络限制及诊断码见[连接设置与错误排查](docs/CONNECTIONS.md)。

## 图库和图片保存

生成的原图保存在酒馆用户的图片目录中，聊天消息保存图片引用和生图记录。图库可按角色、聊天和日期浏览图片，支持放大查看、下载、批量选择和清理。删除原图也会使引用它的聊天图片失效，请在确认后再清理。

缩略图用于加快图库列表显示，不会替代原图。「刷新列表」会重新读取图片，并为缺少缩略图的旧图片补建缓存；已有缩略图会复用。此操作不会调用 NovelAI。

通过手机访问电脑上运行的 SillyTavern 时，图片仍保存在电脑端的酒馆目录。各平台的实际文件位置见[图片分类与存储位置](docs/ARCHIVES.md)。

## 世界书和正则

内置提示词提供让模型输出图片标签的提示规则，正则负责清理上下文标签。首次启用安装配套正则；内置模式下可在「提示词」页导入正则。外部世界书请在酒馆内管理。

切换来源不会关闭或删除已有世界书，请避免同时启用重复指令。两种模式都保留自定义捕捉标签，默认使用 `image###` / `###`。内置运行正文会同步使用已确认的起止标签；外部世界书与无法识别的自定义正文格式需手动核对。

## 常见问题

**回复里有标签，但没有生成按钮。** 确认配套正则已启用，消息符合起始和结束标签格式，并检查「提示词」页当前捕捉标签是否与输出一致。

**自动模式没有处理旧图片标签。** 自动模式只处理启用后新产生的最新 AI 回复。打开旧聊天时，请点击该标签旁的生成按钮。

**使用 Vibe 时提示连接失败。** Vibe 生图使用当前选择的官方或自定义连接，请确认已保存该连接的可用 Key，且当前设备能访问对应生图接口；在线编码还需要该连接支持编码接口。

**更新后界面看起来没有变化。** 更新插件文件后完整刷新酒馆页面；已打开的标签页会继续运行刷新前载入的脚本。

**想备份图片或设置。** 配置、Vibe、聊天引用和原图分别由酒馆保存。迁移或重装时请保留原酒馆用户数据；图片目录和各类文件位置见[图片说明](docs/ARCHIVES.md)。

## 调用费用

生图、Vibe 在线编码和例图生成可能消耗额度，具体以当前服务和账号的计费规则为准。测试生图会实际调用接口；导入已有编码的 Vibe、导入配置和查看本地图库不会额外生图。
